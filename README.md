# iknalos.github.io

Personal portfolio — live at **[iknalos.github.io](https://iknalos.github.io/)**.

Single-file site (`index.html`, no build step). The background is a real-time
Three.js solar system adapted from my [ThreeBody](https://github.com/iknalos/ThreeBody)
N-body visualizer: animated fbm sun shader, NASA-derived planet textures,
Kepler-speed orbits, and a scroll-linked camera fly-through.

## Sections

1. About
2. Experience
3. Technical Projects
4. Fun Projects
5. Contact

## Run locally

```
python -m http.server 8080
# open http://localhost:8080
```
